This covers everyday use of CIRCHATCH — selecting circles and hatching them on your current layer. Loading the routine into AutoCAD (APPLOAD, or a startup suite) is covered separately by whoever manages your CAD setup.

01

Overview

One command that fills every circle in a selection with a solid hatch, always on whatever layer is current when you run it. This page is the reference for using it — not for installing it.

Set the layer you want the fill to land on as current, run CIRCHATCH, and select circles the same way you'd select anything else in AutoCAD — window, crossing, fence, or one at a time holding Shift. Press Enter, and every circle in that selection gets its own associative SOLID hatch.

Anything in the selection that isn't a CIRCLE entity — walls, blocks, text, something round that was actually drawn with ELLIPSE — is left exactly as it was. Nothing else in the drawing is touched, and a circle's own layer never changes.

Selection filter

CIRCLE only

Anything else caught in the window — text, blocks, lines, an ELLIPSE-drawn circle — is ignored automatically.

Hatch pattern

SOLID, associative

Stretch or move the circle later and the fill follows it.

Hatch layer

Whatever's current

Set it before you run the command — not the circle's own layer, whatever that happens to be.

Locked current layer

Blocked, on purpose

The command stops before it even asks you to select anything, and says so.

Worth knowing up front

The command line reports exactly what happened once it's done — how many circles were hatched, and, only if it occurred, how many objects couldn't be. That one line is worth reading before assuming a run did or didn't work.

02

Daily Workflow

What actually happens, in order, from setting a layer to reading the result. The step marked automatic needs nothing from you.

1

Set your current layer

Click a layer name in the Layers panel (or type CLAYER) so it shows as current. This is the layer every hatch from this run lands on, regardless of what layer the circles themselves live on.

2

Run CIRCHATCH

Type it at the command line, same as LINE or ZOOM.

3

Select circles

Window, crossing, fence, pick one at a time with Shift — anything AutoCAD's normal selection accepts. Press Enter when you're done.

4

Each circle gets hatchedautomatic

Every CIRCLE entity in the selection gets its own solid, associative hatch on your current layer. Anything else you swept up in the same window is skipped without complaint.

5

Read the result

One line on the command line: how many circles were hatched, and — only if it happened — how many couldn't be.

Locked current layer

CIRCHATCH checks before it does anything else. If the layer that's current is locked, it says so immediately and stops — it will not switch you to a different layer or ask which one to use instead. Unlock it, or make a different layer current, and run the command again.

What to notice

The outline colors above stand in for each circle's own layer — CIRCHATCH never changes them. Every fill instead takes the color of whichever layer you picked as current before dragging, even for circles from a different layer entirely. Only the six actual circles ever get filled; the dashed rectangle, the line, the text, and the shape drawn with ELLIPSE are never touched no matter how you drag over them.
